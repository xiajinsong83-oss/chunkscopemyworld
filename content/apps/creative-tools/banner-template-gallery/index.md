## About the gallery

Each design is a **pattern list** you can build in survival or preview in the **Banner Editor**. Click "Customize in Banner Editor" to open the design with its patterns applied.

## Patterns reference

| Pattern | Recipe / source |
|---|---|
| base | Base color |
| stripe_center | 2×1 center stripe |
| creeper | Creeper face (skull pattern) |
| skull | Skull pattern |
| flower | Flower pattern |
| cross | Cross (loom) |
| bordure | Border (loom) |

**Tip:** combine a base + 2–3 patterns for most classic looks; the creeper and skull faces are the most recognizable.
