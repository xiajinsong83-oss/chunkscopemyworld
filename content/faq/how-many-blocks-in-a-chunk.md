# How many blocks are in a Minecraft chunk?

In Minecraft (Java 1.18+ and Bedrock), a **chunk is 16 blocks wide × 16 blocks long × 384 blocks tall**. That's 256 blocks per horizontal layer, or **98,304 blocks in a fully generated chunk**.

## Chunk dimensions

- **Horizontal**: 16 × 16 = 256 blocks per Y layer
- **Vertical**: Y from **-64 to 320** = 384 buildable levels
- **Total blocks**: 16 × 16 × 384 = **98,304**

Before 1.18 the height was only 256 (Y 0–255), so old chunks have fewer blocks.

## Why chunks matter

The game generates and updates the world **chunk by chunk**, which is why builds, farms and redstone are usually planned around chunk borders. In Java you can press **F3+G** to see chunk borders.
