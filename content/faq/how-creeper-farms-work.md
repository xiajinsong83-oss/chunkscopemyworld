# How do creeper farms work in Minecraft?

A **creeper farm** is a dark room that spawns only creepers (filtering out other mobs) and funnels them to a kill chamber. It's the fastest way to get gunpowder for TNT and fireworks.

## The core trick: only creepers fit

Creepers are **2 blocks tall but 1 block wide**. Spiders are 2×1 too but spawn on a 3×3 space, and other mobs need more height. By using **trapdoors set to make a 2-high, 1-wide opening**, only creepers and zombies pass — and with cats placed to scare creepers toward a kill point, you get clean creeper-only drops.

## Spawn conditions for creepers

- **Light level 0** (dark room)
- **1.5+ blocks** of vertical space (trapdoor gap counts)
- On solid blocks
- The room must be **spawn-proofed** around it (light up caves) to use the mob cap

## Basic build steps

1. Build a dark chamber (e.g. 8×8×4) high in the sky so no other mobs spawn below.
2. Roof with trapdoors creating a 1-block-wide channel.
3. Place cats around the drop to scare creepers in.
4. Drop them to a 2×1 kill chamber where you one-hit them.
