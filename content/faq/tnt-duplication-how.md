# How does TNT duplication work in Minecraft (and is it still possible)?

**TNT duplication** (TNT duping) lets one TNT block produce unlimited copies using a timing exploit with pistons and water. **It was patched in Minecraft 1.19** — the classic designs no longer work in current versions.

## How the exploit worked (historical)

The old designs relied on a TNT block being pushed by a piston at the exact tick it exploded, duplicating the entity before the block was consumed. Machines used an **observer + piston** loop timed to 0-tick movement.

## Current status by version

| Version | Status |
|---|---|
| 1.18 and earlier | Classic TNT duping works |
| **1.19+ (1.21, 1.21.x)** | **Patched** — no TNT duplication |

## What to use instead

For large-scale mining and quarrying without duping:

- **Piston-based flying machines** for strip mining.
- **TNT canons** loaded by hand or by a hopper-fed machine — still work fine.
- Our [redstone basics guide](/guides/redstone/redstone-basics-guide/) covers timing and piston logic that still power every modern machine.

## Note

TNT duping is **not a bug you should rely on** for a stable base — Mojang patches it every major update. Build around confirmed mechanics instead.
