# Java vs Bedrock farms — which rates should I trust?

Farms measure output differently per edition because the **spawn rules differ**.

## Where they agree

- Iron farms: 6-villager designs produce within 10% on both editions.
- Sugarcane / bamboo / cactus: identical growth ticks.
- Nether portal linking: identical 1:8 rule.

## Where they differ

| Mechanic | Java | Bedrock |
|---|---|---|
| Mob cap | Per player (70 hostile) | Per dimension (200+), shared by all players |
| Simulation distance | Loaded chunks follow player | Fixed by setting (default 4 — raise to 6+) |
| Slime chunks | Seed-based, stable | Same since 1.18; older worlds differ |
| Redstone | 0-tick, quasi-connectivity work | No quasi-connectivity — some designs break |
| Villager workstation claim | Instant | Delayed up to a minute |

## Rule of thumb

Trust ChunkScope numbers on both editions **when the page says "Java & Bedrock"**. For redstone designs, always build on Bedrock-compatible layouts (no quasi-connectivity tricks), and verify rates with the [Farm Output Calculator](/apps/farm-calculator/).
