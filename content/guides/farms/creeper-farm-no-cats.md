# No-Cat Creeper Farm

Most creeper farms need cats to scare creepers off ledges. This design skips cats entirely — creepers are the *only* mob that fits the 2-block spawn gap, so no other hostile mob spawns at all.

## The trick

Creepers are 1.8 blocks tall. Build a **2-block-high, 1-block-wide** spawning corridor: zombies, skeletons and spiders (all taller than 2) can't spawn. Only creepers appear, then fall into the kill chamber.

## Materials

| Item | Amount |
|---|---|
| Solid blocks | ~180 (deepslate/tuff) |
| Scaffolding or trapdoors | 4 |
| Water buckets | 2 |
| Hopper + chest | 1 set |
| Redstone dust + repeaters | ~30 |

## Build steps

1. Find a spot **128+ blocks away** from other farms so the mob cap stays yours.
2. Build a 17×9 roof at Y = 12 with 2-block corridors, each 1 block wide.
3. Water streams push creepers to the central drop shaft.
4. Kill chamber: 2-block drop onto hoppers, or magma + hopper minecart.
5. AFK 24 blocks above the center. Expected output: **~1,500 gunpowder/hour**.

## Why no cats?

Cats scare creepers into *running away*, which can stall rates. Corridor-only spawning is more reliable, cheaper, and works identically on Java and Bedrock.
