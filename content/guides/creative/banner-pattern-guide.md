Banners are your flag canvas. With a **loom** you layer up to 6 patterns onto one base color to build anything from a simple stripe to a creeper face.

## How a banner works

- Start with a **base banner** (any color, 1×1 or 2×3).
- Use a **loom** + **dye** to apply patterns one at a time — each pattern replaces the matching pixels of the current banner.
- Max **6 patterns** per banner (the base counts as 1).

## Every loom pattern

| Pattern | Look |
|---|---|
| Creeper charge | Creeper face (from a creeper head) |
| Skull charge | Skull face (from a wither skeleton skull) |
| Flower charge | Flower shape |
| Globe | World sphere (from a globe) |
| Border / bordure | Outer edge |
| Stripe center | Vertical center stripe |
| Half / field | Colored half |
| Cross | Full cross |
| Diagonal | Diagonal stripes |
| Brick / gradient | Brick or gradient fill |

## How to get patterns

- Most patterns need a **paper + dye + an item** on the loom (e.g. creeper head for the creeper face).
- Some are made from **paper + dye alone** (stripe, border, cross).

## Classic designs

- **Creeper face**: green base + creeper charge (dark green).
- **Skull flag**: white base + skull charge (black).
- **Tri-color**: base + stripe center + border, three colors.

Apply the same pattern to a **shield** (craft shield + banner) to carry your colors into battle.
